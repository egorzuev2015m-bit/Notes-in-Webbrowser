# 📝 Notes App

Красивое веб-приложение для заметок в стиле **glassmorphism** (матовое стекло) 
с фиолетово-неоновой атмосферой ночного леса.

## ✨ Возможности

- 🔐 **Авторизация** — вход по имени пользователя (сохраняется в браузере).
- 👋 **Приветствие** — на главной отображается «Привет, [имя]!» и аватар с первой буквой.
- 🚪 **Выход** — кнопка «Выйти» очищает сессию и возвращает на страницу входа.
- 🗒️ **Заметки** — создание, редактирование и удаление через модальное окно.
- 🔍 **Поиск** — фильтрация заметок по заголовку и тексту в реальном времени.
- 💎 **Стеклянный дизайн** — полупрозрачные блоки с размытием и свечением.
- 📱 **Адаптивность** — корректно работает на телефонах и планшетах.

## 🛠️ Технологии

- **HTML5** — структура страниц.
- **CSS3** — стили, `backdrop-filter`, анимации, адаптивная вёрстка.
- **JavaScript (Vanilla)** — логика входа, заметок, поиска, работа с `localStorage`.
- **Boxicons** — иконки.
- **Google Fonts (Poppins)** — шрифт.

## 🚀 Как запустить

1. Скачай или склонируй проект.
2. Убедись, что файл `img.png` (фон) лежит в корне проекта рядом с HTML-файлами.
3. Открой `index.html` в браузере — или запусти через **Live Server** в VS Code.

> Если открываешь просто двойным кликом — всё работает, но для удобства 
> рекомендую использовать расширение **Live Server** (VS Code).

## 🔄 Как это работает

1. Пользователь открывает `index.html` — видит форму входа.
2. Вводит имя → оно сохраняется в `localStorage` → переход на `dashboard.html`.
3. Если имя уже сохранено, при повторном заходе форма входа **пропускается** — сразу открывается дашборд.
4. На главной странице:
   - В углу — «Привет, [имя]!» и аватар с первой буквой.
   - Можно создавать заметки через кнопку **«+ Новая заметка»**.
   - Каждую заметку можно **редактировать** или **удалить**.
   - Работает **поиск** по заголовку и тексту.
5. Нажатие **«Выйти»** удаляет имя из `localStorage` и возвращает на форму входа.

## 🎨 Кастомизация

- **Фон:** замени `img.png` на свою картинку (того же стиля).
- **Цвета:** основные оттенки заданы в `style.css` — ищи `rgba(255, 255, 255, ...)` и `#e040fb`.
- **Шрифт:** измени ссылку в `@import url(...)` в начале `style.css`.
- **Иконки:** подключены с [Boxicons](https://boxicons.com/).

## 💾 Хранение данных

Сейчас заметки **не сохраняются** между сессиями — они живут только во время работы вкладки.
Если хочешь, чтобы они сохранялись — нужно добавить запись массива заметок в `localStorage` 
и загрузку при открытии страницы. (Можно дописать позже.)
